# 収録と公開前確認の方針

この案内は、実際のサービスの管理画面をブラウザで操作して収録するものです。手順の説明、クリック位置の強調、個別情報を隠す処理を編集で加えます。操作していない画面を、実際に完了した操作として表示しません。

## 収録した範囲を明示する

- 各章の収録日は `chapters.js` の `recordedAt`、収録した操作と未収録の操作は `coverageNote` に記載します。動画ページにも表示します。
- 登録・認証・支払情報の入力・権限の発行などが収録前に完了している場合、現在の確認画面と、最終操作そのものの録画を区別します。
- ログイン済み画面を撮っても、ログイン情報の入力や認証を収録したことにはしません。Cloudflare の第 04 章はメール「確認済み」の表示だけ、Lステップの第 08 章はログイン後の取得元表示の確認だけを対象にしています。
- 設定の下書きや確認画面までを撮った場合、登録・有効化・発行まで完了した動画として案内しません。
- 手順のために既存の秘密の値を再発行したり、不要なアクセス権を追加したりしません。
- 動画の設定は、説明する構成での一例です。用途によって変わる設定や、配備後に更新が必要な仮の値は説明に記載します。
- 第 07 章のファイル編集は、公開用の空欄の見本と説明用の伏せ字で実演します。実際に取得した秘密の値を表示して編集する録画とは区別し、実際の値は保護された保存先だけで扱います。

## 公開用ファイルの確認

未加工の録画や秘密の値を保存したファイルは、公開用リポジトリに置きません。公開用に編集した動画は、次を全編で確認してから `reviewed: true` にします。

1. アカウント名、氏名、メールアドレス、アイコン、プロバイダー名、個別の ID・URL、秘密の値などが読み取れないこと。スクロール中・画面切り替え中・入力候補・通知も確認します。
2. コピーや入力の前後を含め、シークレット・トークンが露出していないこと。隠す範囲は文字の一部だけでなく、その情報全体を覆います。
3. 字幕・説明・音声・ファイル名・動画の付加情報にも、個人や実際のアカウントを識別する情報が含まれないこと。
4. 画質と容量を調整した後も、操作するメニュー・項目名と説明が読め、ブラウザで再生できること。
5. 動画と `coverageNote`・手順・一覧の収録範囲が一致すること。未収録の最終操作がある場合は、その旨が動画を見る前に分かること。

## 第三者の画面を載せる根拠

動画には LINE Developers・Cloudflare・Lステップ・L Harness の管理画面が映ります。これらは、利用者が自分のアカウントで行う操作の手順を説明するためだけに、必要な範囲で収録したもので、各サービスの画面・ロゴ・名称の権利はそれぞれの提供元にあります（提供元の推奨・提携を示すものではありません。[人が行う操作の案内](README.md)に明記）。ロゴを素材として切り出したり、画面を別の目的に使ったりしません。提供元から掲載を控えるよう求められた場合は、該当する動画を取り下げます。

公開後に元サービスの画面や手順が変わった場合は、収録日を参考に更新します。`reviewed: false` の章は、公開前確認を終えた動画として再生しません。
